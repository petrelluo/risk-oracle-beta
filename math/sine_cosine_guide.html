01 · Foundation

Start with the parent graphs

Before any stretching or shifting, you need the shape of sine and cosine burned into your brain. They're the same wavy curve — just starting in different places.

The 5 key points (memorize these!)

For y = sin x, the y-values cycle: 0 → 1 → 0 → −1 → 0  (starts at zero, goes up)

For y = cos x, the y-values cycle: 1 → 0 → −1 → 0 → 1  (starts at the top)

The big insight: cosine is just sine shifted left by π/2. They are literally the same wave! So once you know how to handle one, you know how to handle both.
02 · The Formula

One formula does everything

Every problem in 8.4 — no matter how scary it looks — fits this single template:

y = a · sin( b(x − h) ) + k
a = amplitude (vertical stretch) b = horizontal stretch/shrink h = phase shift (left/right) k = vertical shift (up/down)

(Same template works for cosine — just swap sin for cos.)

What each letter does to the graph

LetterWhat it controlsEffect
a Amplitude The wave goes up to |a| and down to −|a|. If a is negative, the wave is flipped upside down.
b Period Period = 2π / |b|. Bigger b = wave squished tighter. Smaller b = wave stretched wide.
h Phase shift The whole wave slides right by h (if h > 0) or left (if h < 0).
k Vertical shift The midline of the wave moves from y = 0 to y = k. Everything moves up (or down).
Watch out! The formula has (x − h), with a minus. So if you see sin(x + π/3), that's sin(x − (−π/3)), meaning h = −π/3 and the graph shifts left.

04 · The Recipe

The 5-step recipe (use this every single time)

When you see a graphing problem, don't panic — just follow the steps in this order. They never change.

Identify a, b, h, k

Match the equation to y = a·sin(b(x−h)) + k. Be careful with signs! If you see sin(2x + π), factor first: sin(2(x + π/2)), so h = −π/2.

Find the period

Period = 2π / |b|. This is how wide ONE full wave is.

Find the midline and amplitude

The midline is y = k. The wave goes up to k + |a| (max) and down to k − |a| (min).

Find the 5 key x-values

Start at x = h (this is the "new zero"). Divide the period into 4 equal pieces. The 5 key x-values are:
h, h + period/4, h + period/2, h + 3·period/4, h + period

Plot the 5 key points and connect smoothly

For sine: y-pattern is mid → max → mid → min → mid.
For cosine: y-pattern is max → mid → min → mid → max.
If a is negative, flip max and min!

07 · Challenge Example

Example 3: y = −2 sin(2x + π) − 1

All four transformations — including a negative amplitude (flip) AND a phase shift hidden inside the parentheses.

Example 3 · Challenge

y = −2 sin(2x + π) − 1

⚠️ First: factor out the b inside the parentheses!

The phase shift is the value of h, not the constant you see. We need to write the equation in standard form b(x − h).

2x + π = 2(x + π/2) = 2(x − (−π/2))

So h = −π/2  (shifts left by π/2).

Identify:  a = −2,  b = 2,  h = −π/2,  k = −1

Period:  2π / 2 = π

Amplitude:  |−2| = 2  (but negative → flipped upside down!)

Midline:  y = −1

Key x-values

Start at x = h = −π/2. Period/4 = π/4.

−π/2,   −π/4,   0,   π/4,   π/2

For sine the pattern is mid → max → mid → min → mid. But a is negative, so we flip: mid → min → mid → max → mid.

With midline y = −1 and amplitude 2 (max = 1, min = −3):

y:   −1,   −3,   −1,   1,   −1

08 · Cheat Sheet

One-page cheat sheet

The formula

y = a · sin(b(x − h)) + k    or    y = a · cos(b(x − h)) + k

The recipe

  1. Identify a, b, h, k — factor out b if needed.
  2. Find period = 2π / |b|.
  3. Find midline y = k and amplitude |a|.
  4. Find 5 key x-values: start at h, add period/4 each step.
  5. Plot the 5 points using the y-pattern:
    • sin: mid → max → mid → min → mid  (flip if a < 0)
    • cos: max → mid → min → mid → max  (flip if a < 0)

The traps

  • Sign of h: the formula uses (x − h). So sin(x + π/2) = sin(x − (−π/2)), meaning h = −π/2 (shifts left).
  • Factor first: sin(2x + π) is NOT a shift of π. Factor: 2(x + π/2), so the shift is π/2 (not π!).
  • Negative a: the wave flips upside down — max and min swap.
Mantra for graphing: "Match, period, midline, key x's, key y's." Say it out loud while you work. Five steps. Every time.
